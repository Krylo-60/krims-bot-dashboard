Progression

⚡ Leveling, Message XP & Leaderboards

Real-time text & voice XP engine with dual-mode leaderboards and quiet cross-server leveling.

Every active chat message earns 15 to 25 XP with a 60-second anti-spam cooldown. When a user has an active Top.gg Vote Booster, all XP is automatically doubled (2.0x Multiplier)!

XP Calculation Formula:

Required XP for Level L = 5 * (L²) + (50 * L) + 100

Rank Cards (/rank or !rank):

Shows current level, total XP, progress bar, message counter, server rank position, and active vote booster status.

Interactive Leaderboards (/leaderboard or !leaderboard):

  • [💬 Messages] — Ranks users by message activity count.
  • [⚡ XP & Levels] — Ranks users by total XP and levels.
  • [🗳️ Vote for 2x XP] — Direct link to vote on Top.gg.

Strict Quiet Leveling Policy:

Level-up announcements are sent exclusively in the official Krims Code Support Server (#💬・𝖦eneral-𝖢hat). In all other servers, leveling is quiet and non-intrusive.

⚙️ Custom Bot Fleet Spawner

Spawn your own custom-branded Discord bot using the Krims Code AI brain at $0 cost.

Server owners can spawn their very own custom-branded Discord bots running the Krims Code AI multi-process engine with zero hosting fees:

  1. Go to the Discord Developer Portal.
  2. Click New Application and name your bot.
  3. Under the Bot tab, enable all 3 Privileged Gateway Intents.
  4. Copy your bot token and run /setupbot token:<your-token> in your server!
Admin

🛡️ Moderation & AutoMod Protection

Full suite of administrative moderation tools to maintain server safety.

  • !warn @user <reason> — Issue an official warning.
  • !mute @user <time> <reason> — Discord Timeout restriction.
  • !unmute @user — Lift timeout.
  • !kick @user <reason> — Kick member from server.
  • !ban @user <reason> — Ban member permanently.
  • !purge <1-100> — Bulk delete recent channel messages.
  • !lockdown — Lock channel speaking permissions.
  • !unlock — Restore channel speaking permissions.
  • !slowmode <seconds> — Channel rate-limit slowmode.
