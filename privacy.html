Privacy Policy

Last updated: October 2026 • Krims Code AI & Fleet Ecosystem

This Privacy Policy applies to the Krims Code AI Discord application suite, including Krims Code AI (Client ID: 1523794466740371586), Krims Code Premium (Client ID: 1562586215822266599), Krims Code Alpha, Krims Code Beta, and the official web dashboard hosted at krims-bot-dashboard.vercel.app (collectively referred to as "the Service", "the Bot", "we", "us", or "our"), operated by Krylo and Krims Code Studio.

1. Information We Collect

To deliver autonomous moderation, conversational AI assistance, cross-server economy, and server operations, we collect only the minimal data necessary:

  • Discord Identifiers: Public Discord User IDs, Guild (Server) IDs, Channel IDs, and Role IDs required for executing slash commands, tracking XP leveling, managing support tickets, and configuring server preferences.
  • Message Content: Processed ephemerally in real time when the bot is mentioned, replied to, or when executing moderation filters (anti-spam, anti-invite, prohibited words). Messages are never logged permanently for advertising or sale.
  • Leveling & Economy Records: Virtual coin balances, daily streaks, inventory items, and XP experience levels stored per Discord user.
  • Web Dashboard Session Data: Authentication tokens provided via Discord OAuth2 to authenticate server ownership and load your manageable guild list. This token is stored exclusively in your browser's local storage and is never saved to external advertising databases.

2. Purpose of Data Processing

We process your data strictly to provide core bot functionality: executing requested commands, providing AI chat responses, updating member rank cards, enforcing server security, and syncing dashboard configurations.

3. AI Processing & Privacy Safeguards

When users invoke conversational AI features (such as /ask or direct bot mentions), input text is routed to our proprietary neural inference pipeline to generate an immediate response.

  • User prompts are processed in-memory and are not shared with unauthorized third parties.
  • No Discord private messages or member chats are used to train third-party public machine learning models.

4. Data Storage, Retention, and Deletion

Server configuration data (welcome messages, role rewards, prefix preferences) and user economy balances are stored securely in encrypted cloud databases (SQLite WAL & Neon PostgreSQL).

  • Data Deletion Requests: Server administrators or users may request complete erasure of their stored guild or user records at any time by contacting us via our Discord Support Server or via email at 71krishivpb@gmail.com.
  • Bot Removal: If Krims Code AI is removed from a server, stored guild configurations remain inactive and can be completely wiped upon request.

5. Data Sharing & Third-Party Disclosure

We never sell, lease, trade, or monetize user data to third parties, advertising brokers, or marketing firms. Data is only exchanged with Discord's official APIs to fulfill bot interactions in accordance with Discord's Developer Terms.
